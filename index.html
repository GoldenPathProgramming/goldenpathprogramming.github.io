The Path Walked, Yet Unwritten...

It will take me some time to write out every step of the Path, but, unlike other tutorial series, the code is essentially already written. The final code of the Path will be improved compared to the initial release of my game engine, but you may continue the Path immediately by reading through the NSMGEngine source code, which you downloaded in the "Sanity Check" step. NSMGE is the engine I used to release my commercial games on Steam, and is what the Path is intended to teach. Below is a roadmap for the Path. It is a general outline of what I intend to create for the Path, but it is subject to change.
